# Use a QA runtime with thin agent skill adapters

The TypeScript **QA Runtime** is the source of truth for orchestration, Playwright execution, artifacts, validation, and reports, while Codex, Claude Code, and Cursor integrations remain thin **Skill Adapters**. Making instruction files the engine would couple behavior to each agent's prompting and skill-composition semantics; centralizing deterministic behavior keeps outputs reproducible while preserving independently callable agent skills. Standalone adapters and orchestrated workflows invoke the same typed **QA Operations**, and only the runtime-managed **Run Workspace** registers their explicit inputs and outputs—operations never discover dependencies by scanning for recent files. The runtime embeds no LLM provider: coding agents create provenance-marked **Agent Drafts**, and the runtime validates, canonicalizes, and registers them as **Canonical Artifacts** without silently repairing invalid output.
